# ADR Author

Use when an architectural decision needs to become a durable record.

Outputs:
- decision statement
- context
- chosen option
- rejected alternatives
- implications

Default roles:
- Tech Lead
- Docs Architect
- Reviewer when risk is material

- `AGENTS.md`
