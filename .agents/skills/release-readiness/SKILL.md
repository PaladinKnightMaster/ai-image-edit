# Release Readiness

Use when deciding whether the project is ready for a new exposure level.

Outputs:
- blockers
- evidence
- severity
- mitigation plan
- ship or no-ship recommendation

Default roles:
- Reviewer
- Release Guard
- UX Reviewer
- DevOps Release when operational risk matters
