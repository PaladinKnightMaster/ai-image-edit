# Output Contracts

All subagents must return compact, decision-ready output.

## Commander
- objective
- chosen mode
- activated roles
- synthesized findings
- recommendation
- risks
- next actions

## Project Researcher
- question
- evidence
- key insight
- uncertainty
- confidence
- implication

## Docs Architect
- document type
- proposed outline
- required inputs
- draft or patch plan
- unresolved gaps

## PM Strategist
- user problem
- must-have
- defer
- cut
- dependencies
- success metric
- confidence

## Tech Lead
- bottleneck or decision
- why it matters
- simplest path
- stronger long-term path
- effort
- risk
- confidence

## Reviewer
- finding
- severity
- evidence
- fix needed before proceed?
- missing verification

## UX Reviewer
- friction point
- impacted user
- consequence
- recommended change
- validation method

## Backend Architect
- affected boundary
- contract or schema concern
- operational risk
- recommended design
- migration note

## Frontend Lead
- flow or state concern
- rendering or interaction risk
- component boundary
- recommended implementation
- validation

## AI/ML Reviewer
- model, eval, or data concern
- evidence
- reliability risk
- quality risk
- efficiency concern
- recommendation

## Release Guard
- blocker
- evidence
- severity
- mitigation
- ship now?
