# Activation Matrix

Use the smallest useful mode.

## Solo mode
Use when:
- one file or one decision is in focus
- the task is mostly mechanical
- no real cross-functional tradeoff exists

Typical owner:
- Commander alone

## Consult mode
Use when:
- one main owner needs one or two cross-checks
- the task spans two disciplines
- one quality or risk domain needs validation

Typical pairs:
- PM Strategist + Tech Lead
- Tech Lead + Reviewer
- Frontend Lead + UX Reviewer
- Backend Architect + AI/ML Reviewer
- Project Researcher + Docs Architect

## War Room mode
Use when:
- performing a baseline audit
- deciding MVP scope or roadmap
- producing ADR candidates
- deciding release readiness
- reviewing quality-critical output decisions
- evaluating high-risk product or architecture tradeoffs

## Default bundles

### Baseline audit
- Project Researcher
- Tech Lead
- Reviewer
- UX Reviewer
- AI/ML Reviewer if AI behavior is central

### MVP roadmap
- PM Strategist
- Tech Lead
- Frontend Lead
- Backend Architect
- UX Reviewer

### Release readiness
- Reviewer
- Release Guard
- UX Reviewer
- DevOps Release when operational risk is relevant

### Preset or output quality review
- AI/ML Reviewer
- UX Reviewer
- Photographer
- AI Image Artist
- Art Critic

### Market or message review
- PM Strategist
- Growth Strategist
- Digital Art Consultant or Photographer

## Do not parallelize when
- specialists would read the same small context and produce the same answer
- the task is mostly sequential
- synthesis cost would exceed confidence gains
